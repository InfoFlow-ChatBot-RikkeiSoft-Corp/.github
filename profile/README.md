# InflowChat - RikkeiSoft Corp & KNU

InflowChat is an advanced AI-powered chatbot developed collaboratively by **RikkeiSoft Corp** and **KNU**. Designed to improve workplace communication and productivity, the system leverages generative AI to enhance accessibility, reduce user techno-stress, and streamline digital interactions. This repository hosts the implementation of InflowChat, which provides dynamic features tailored for employees and admins to optimize organizational workflows.

---

## 🌟 Key Features

- **Authentication System**:
  - Employee/Admin registration, login, and logout via **Google SSO**.
- **Employee Interface**:
  - Ask questions and receive accurate answers with references.
  - View chat history, including the last 10 interactions.
  - Automatically declines questions beyond the chatbot's scope.
- **Admin Interface**:
  - Upload, delete, and manage documents (PDF, DOC, and web links).
  - Update chatbot settings, including prompts and system configurations.
- **Enhanced Productivity**:
  - Real-time chatbot responses save time and improve user experience.
  - Designed to help users overcome techno-phobia and adopt AI tools seamlessly.

## 🛠️ Tech Stack

- **Frontend**: TypeScript, CSS
- **Backend**: Python (Flask)
- **Database**: VectorDB
- **Infrastructure**: Google Cloud Services
- **APIs**: Gemini API, Google SSO
- **Project Management**: Trello, Git, Postman

---

## 📚 System Overview

1. **Authentication**:
   - Employees and admins authenticate using a secure Google Single Sign-On (SSO) system.
2. **Employee Features**:
   - Query the chatbot and get accurate answers with relevant references.
   - Maintain and review previous interactions with the chat history feature.
3. **Admin Features**:
   - Manage documents and chatbot settings to keep the system updated.
   - Enable prompt management to ensure accurate responses to queries.
